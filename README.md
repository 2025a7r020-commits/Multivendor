# AI-Driven Network Security Compliance Auditor

Browser-based prototype for auditing Cisco IOS, Juniper JunOS, Fortinet FortiOS configurations.

## Live Demo
https://2025a7r020-commits.github.io/network-security-auditor/

## Features
- Auto vendor detection
- 12 security rules
- Compliance score 0-100%
- Download TXT/CSV/JSON reports
- No server needed
